# Facebook Ad Library Scraper Promotion Notes

## Positioning

Collect structured public Facebook Ad Library ad records for competitor creative research, brand monitoring, and public ad-transparency analysis.

## Best small demo

- Keyword: `Nike`
- Country: `US`
- Status: `active`
- Platforms: `facebook`, `instagram`
- Maximum results: `1`
- Proxy: Residential

Show the input, one clean ad row, media fields when available, and JSON or CSV export.

## LinkedIn draft

I published a Facebook Ad Library Scraper on Apify for structured public ad-transparency research.

It collects public fields such as ad ID, advertiser page, creative text, headline, CTA, media URLs, run dates, destination URL, platforms, and spend/impression ranges when Meta discloses them.

The safest first run is intentionally tiny: Nike, US, active ads, Facebook + Instagram, one result, Residential proxy. Inspect the output, then expand to more keywords, Page IDs, countries, or result limits.

Useful for competitor creative research, brand monitoring, public ad tracking, and campaign messaging analysis.

## Reddit or Discord draft

I built an Apify Actor that turns public Facebook Ad Library pages into structured JSON/CSV data. It supports keyword, advertiser-name, and Page ID searches, country/status/category filters, platform filters, and result limits.

For a low-cost check, run Nike + US + active + one result with Residential proxy. Feedback on the schema and useful ad-research fields is welcome.
